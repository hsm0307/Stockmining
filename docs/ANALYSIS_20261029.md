# 정확도 개선 분석 (2026-10-29)

사용자 질문 다섯 가지에 대한 분석 기록이다.
1. 어떻게 세분화하면 더 정확해지나
2. 노을 같은 첫 상한가를 맞히려면
3. 시가에 진입했을 때 상한가로 마감할 확률은
4. 연속 상한가는 얼마나 맞히나
5. 상한가·터치 후 하락·미도달(·점상)로 나눠 학습하면 나아지나

각 분석은 여러 에이전트로 나눠 진행했다. 결과마다 다른 에이전트가 독립 코드로 다시 계산했고, 아래에는 그 재검증을 통과한 수치만 적었다.

## 자료와 방법

- **예측 자료:** 운영 모델 v5의 10년 분기 재학습 walk-forward 예측(2017-01 ~ 2026-10).
  - 그날 상위 50·100개, 그리고 t일 상한가 마감 종목 13,012건 전부에 다음 날 시가·고가·종가와 t일 특징을 붙였다.
- **기간:** dev = 2017~2023, 보류 = 2024~. 표의 수치는 별다른 표시가 없으면 "dev / 보류" 순서다.
- **주의:** 특징 파일 전체는 메모리 한도 때문에 읽지 않았다. 학습 실험은 이 부분 자료에서 나무 수를 고정하고 했으므로, 결론을 확정하려면 전체 특징으로 10년 walk-forward를 다시 돌려야 한다.

## 1. 세분화

- **종목 속성으로 나누는 것은 효과가 없다.** 시총, 우선주, 시장, 관리종목, 저가주, 거래대금으로 고확신(HC, prob ≥ 0.15) 적중률이 일관되게 갈리지 않는다.
  - 예: 우선주 34.5/28.4% vs 보통주 35.3/27.3%.
  - 제외 규칙 15종 중 두 기간 모두 +1.5%p를 넘은 것은 없었다. 이전 실험(`outputs/tables/g5_segment_models_y_up.csv`)의 세그먼트별 모델도 효과가 없었다.
- **효과가 견고한 축은 t일 상한가가 어떻게 만들어졌는지다.**

  | HC 픽 (prob ≥ 0.15) | dev | 보류 |
  |---|---|---|
  | t일 점상(시가부터 종가까지 상한가) | 50.2% (269) | 41.5% (183) |
  | t일 비점상 | 24.7% (425) | 23.3% (532) |
  | 장중 첫 상한가 → 2연상 시도 | — | 21.0% (385), 10년 중 8년이 30% 미만 |

  - 규칙 A: HC = (t일 점상 & 상위 50) ∪ (p ≥ 0.15 중 장중 첫 상한가 제외). 결과는 42.3% / 36.9%로, 현행 34.7% / 27.9%보다 높다.
  - 다만 확률 스케일이 정상인 분기만 보면 이득이 +2~4%p로 줄고 신뢰구간이 0을 포함한다. 점상 적중률도 2026년 35.4%로 내려가는 중이다. 일부 조건(장중 첫 상한가 제외, 임계값)은 보류 구간을 본 뒤 고른 것이다.
- 다중검정 규모는 구분 약 300개, dev 그리드 720개다.

## 2. 확률 스케일이 재학습마다 흔들린다

- **현상:** 10년 walk-forward 40개 분기 중 10개에서 하루 최고 prob이 0.01~0.06에 그쳐 HC가 0건이었다. 해당 분기는 2017Q2, 2018Q3, 2020Q2~Q4, 2025Q1·Q3, 2026Q2~Q4이다. 반대로 최고 prob이 0.2~0.29인 분기도 있다.
- **원인 (코드에서 확인):** AP 기준 조기종료가 나무 5~10개에서 멈춘다.
  - 실전 v5의 `best_iter`는 [5, 8, 8]이다.
  - 실전 모델은 `_refit_all`에서 최소 50개로 다시 학습하지만, walk-forward는 5~10개짜리를 그대로 쓴다.
  - 그래서 같은 날 실전 prob이 walk-forward보다 수 배에서 10배 높다.
- **영향:**
  - 하루 안의 순위(P@10)는 거의 그대로다.
  - 하지만 "prob ≥ 0.15" 같은 절대 기준은 재학습마다 뜻이 달라진다. 실전 HC 3/10과 백테스트 HC 정밀도는 직접 비교할 수 없다.
- **추가 근거:** 나무 수를 고정한 이진 모델이 v5보다 나았다(부분 자료에서 상위 100을 다시 순위 매긴 실험, 보류 구간).
  - P@10 +0.64%p [+0.23, +1.04]
  - 하루 0.7개 예산 정밀도 +6.05%p
  - 전일 상한가 종목 안 AUC 0.73 vs 0.59

## 3. 시가 진입 (다음 날 시가 매수 → 종가 매도, 비용 0.25%)

| 픽 | 시가부터 상한가(매수 불가) | 시가 매수 후 상한가 마감 | 평균 수익 |
|---|---|---|---|
| HC (prob ≥ 0.15) | 22.4% / 18.7% | 23.2% / 16.6% | −2.6% / −4.6% |
| 매일 1위 | 12.2% / 22.4% | 15.4% / 16.9% | −2.5% / −5.6% |
| 상위 10 | 2.4% / 5.5% | 6.1% / 8.4% | −1.5% / −3.0% |
| 전일 상한가 종목 전체 | 5.1% / 7.9% | 9.8% / 10.7% | −2.9% / −4.3% |

- **지는 이유:** HC 픽은 시가가 평균 +13.1% / +11.6% 갭업으로 출발하고, 이후 종가까지 −2.7% / −4.5% 내린다. 본전에 필요한 상한가 확률은 34~43%인데 실제는 15~32%다.
- 시가가 상한가인 종목을 따라 사면 체결은 상한가가 풀릴 때만 된다. 그 경우 평균 −7.1% / −10.6%다.
- 09:00 시가가 +5% 이하로 열린 HC는 상한가 마감이 3~7%뿐이다.

## 4. 연속 상한가

- **기본 비율:** 전일 상한가 13,012건 중 다음 날도 상한가 마감은 13.1% / 15.7%다.
  - 1→2연상 10.9% / 13.2%
  - 2→3연상 25.0% / 26.7%
  - 3연상 이상 33.5% / 32.0% (15~21%는 다음 날 거래정지)
  - t일 점상 47.9% / 39.8% (그중 40%는 다음 날 시가가 상한가)
- **HC 정밀도:** 34.6% / 28.0%, 보류 95% 구간 24.6~31.6%다. HC 픽의 98% 이상이 연속 후보다.
- **순위 능력:** 같은 날 안의 AUC는 0.73이다. 상한가 종목 중 prob 1위는 22.9% / 29.3%로, 무작위 12.0% / 14.4%보다 높다.
- **틀린 픽의 결말:** 상한가 근처도 못 감 76%, 터치 후 실패 9~14%, 시가 상한가 후 밀림 5~7%, 거래정지 5~7.5%다.
- **같은 픽 수에서 정밀도를 올린 규칙 (보류 구간):**
  - 상한가 종목 중 하루 1위: 37.7% / 37.4%
  - prob ≥ 0.20: 40.5% / 36.2% (픽 수는 절반)
  - 연속 전용 재순위 모델 + 하루 1개: 37.0%. 다만 같은 상한을 건 prob과의 차이는 +1.7%p로 유의하지 않다.

## 5. 첫 상한가 (전일 상한가가 아닌 종목)

- **비중과 순위:** 전체 상한가의 85.5%가 첫 상한가다. 전날 v5 순위 중앙값은 213위이고, 상위 10 안에 드는 것은 4.1%뿐이다. 연속 상한가는 중앙값 3위, 93.5%가 상위 10 안이다.
- **첫 상한가 후보만 따로 순위를 매겨도:** 1위 5.3% / 5.6%, 상위 5 3.7% / 4.4%다. 다음 날 평균 수익은 −0.35% / −1.33%다.
- **노을(376930) 10/23 첫 상한가:**
  - 전날 실전 순위 36위였다(walk-forward 93위).
  - 10/23은 시가가 상한가(1,670원)였다. 관리종목이다.
  - 분석 에이전트에 따르면 원인은 10/23 08:46 제3자배정 유상증자 공시다. 이 부분은 별도 확인하지 않았다.
  - 다음 날(10/26)은 실전 2위(19.8%)로 맞혔다.
- **조건 탐색 결과:** 손으로 만든 조건 52개, 부분집합 286개 중 두 기간 모두 10%를 넘은 것은 없다.
- **소폭 개선 (재검증 통과):**
  - 첫 상한가 전용 재순위 모델: 보류 상위 5 적중이 4.4%에서 5.4%로 올랐다.
  - 두 시장 합산 상한가 10개 이상인 날은 첫 상한가 1위가 7.5~7.9%다.
- **장 시작 전 새 자료 (DART 공시, NXT 장외 거래, 동시호가):** 외부 자료 분석이라 별도 재검증을 하지 않았다. 과거 데이터가 없는 것은 지금부터 수집해야 평가할 수 있다.

## 6. 3분류 / 4분류(점상 분리) 학습

- **상한가 마감 적중: 효과가 없다.** 상위 100과 상한가 종목 두 유니버스, 두 기간 모두에서 이진, 3분류, 4분류가 비긴다. 차이는 ±1.3%p 안이고 시드 간 흔들림과 같은 크기다.
  - 예: 상위 100 P@10, 보류 0.1238(이진) vs 0.1234(4분류 P2+P3).
  - LightGBM 다중분류는 클래스마다 트리를 따로 학습한다. 그래서 '마감' 클래스는 이진과 같은 신호를 받고, 터치·실패 정보는 이미 특징에 들어 있다.
- **시가 매수 쪽은 보류 구간에서만 효과가 있다.** P(장중 상한가)로 순위를 매기면 상위 100 기준 매수 가능 적중이 +3.8%p [+1.4, +6.1], 시가 진입 수익이 +2.5%p다.
  - 하지만 "매수 가능 상한가"를 정답으로 둔 이진 모델과 같다. 4분류 구조 덕분이 아니다.
  - dev에서는 유의하지 않다.
  - 여전히 시가 진입 수익은 평균 손실이다(−3 ~ −6%).
- **점상 예측:** AUC 0.85~0.91이지만, 같은 수의 경고에서 "t일 점상" 규칙과 정밀도·재현율이 같다(21.4%/48.6% vs 21.0%/47.9%).

## 개선 계획 (우선순위)

1. **조기종료와 확률 스케일 수정.** 고정 나무 수, logloss 기준 조기종료, 최소 반복 수 등을 후보로 두고 10년 walk-forward로 비교한다.
   - 판정은 P@10과 같은 픽 수의 HC 정밀도로 한다.
   - 성공 기준은 최고 prob 중앙값 0.06 미만 분기 0개, 같은 날 실전과 walk-forward의 prob 차이 2배 이내.
2. **HC 기준 변경 (사용자 결정 필요).** 후보는 "상한가 종목 중 하루 1위"(보류 37.4%) 또는 prob ≥ 0.20(36.2%)이다. 장중 첫 상한가 픽은 낮은 확신으로 표시한다.
3. **일일 리포트에 시가 진입 지표 추가.** 시가 상한가면 매수하지 않는다. 09:00 시가가 +5% 이하면 기대가 낮다고 표시한다. 매수 가능 적중률과 시가 진입 순수익을 함께 채점한다.
4. **2단계 재순위 실험.** 연속 상한가용, 매수 가능 상한가용, 첫 상한가용을 각각 분기 재학습 walk-forward로 검증하고, 같은 픽 수와 시드 3개 이상으로 비교한다.
5. **장 시작 전·장 마감 후 자료의 전향적 수집.** 대상은 DART 공시(2017년부터 백필 가능), NXT, KRX 장 마감 후 거래이며, 60~120거래일 뒤에 평가한다.

**효과가 없었던 것:** 세그먼트별 모델, 속성 기준 제외 규칙, 3분류·4분류로 상한가 마감 적중 올리기, isotonic 재보정, 시가→종가 수익 직접 학습, 시가 갭 필터, 노을형 프로파일 규칙.

분석 스크립트와 중간 결과는 세션 임시 폴더에 있었으므로 저장소에는 포함하지 않았다.
