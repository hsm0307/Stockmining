# 최신 데이터 위주 학습 실험 (2026-10-30)

"최신 데이터에 과적합해 달라"는 요청에 대한 실험이다. 최근 시장에 최대한 맞춘 모델이 앞으로의 예측도 더 잘 맞히는지를, 미래 정보 없이 재학습하며 확인했다.

결론: **최근 데이터에 더 맞춘 방식 가운데 공식 모델 v5(최근 3년 학습)를 이긴 것은 없다.**
- 학습 기간을 줄이거나 최근 가중을 세게 줄수록 일관되게 나빠졌다.
- 약하게 맞춘 방식(12개월 창, 반감기 182일, 미세조정, 혼합)은 시드만 바꾼 v5와 같은 수준이다.

## 방법

- **스크립트:** `scripts/recency_study.py`
- **결과표:** `outputs/tables/g5_recency_y_up*.csv`
- **재학습 방식:** 실전 `train_final`과 똑같이, 조기종료로 나무 수를 정한 뒤 마지막 60거래일까지 넣어 다시 학습한다.
  - 가중 학습 구현이 이 방식과 예측값까지 같은 것을 확인했다(최대 차이 0.0).
- **재학습 주기와 기간:** 매월 1일에 그 전 자료로만 다시 학습해 그달을 예측했다(2025-07 ~ 2026-10).
  - 짧은 창은 매주 재학습으로도 다시 확인했다.
- **판정 규칙 (결과를 보기 전에 스크립트 머리말에 고정):**
  - 주 지표: 선택 구간(2025-07 ~ 2026-06, 244일)에서 v5 대비 ΔP@10
  - 통과 조건: 일별 t ≥ 2.7(후보 수만큼 보정), 월평균 t ≥ 2, 12개월 중 9개월 이상 양수
  - 2026-07 이후는 예전 recent_window 연구에서 이미 본 구간이라 '음수가 아님'만 확인했다.
- **검증:** Workflow 에이전트로 세 번 검증했다.
  1. 설계 검토: 미래 정보 누출, 지표 계산
  2. 독립 재계산: 모든 수치가 1e-4 안에서 일치
  3. 반론 검토: 결론을 깨려는 시도

## 결과 (선택 구간 P@10, v5 = 15.86%)

| 방식 | 후보 | P@10 | Δ | t |
|---|---|---|---|---|
| 잡음 기준 | v5, 시드만 바꿈 | 15.49% | −0.37%p | −1.44 |
| 학습 기간 축소 | 12 / 6 / 3 / 2 / 1개월 | 15.33 / 14.51 / 13.69 / 13.24 / 11.93% | −0.5 ~ −3.9%p | −1.8 ~ −7.3 |
| 같은 창, 나무 50개 | 6 / 3개월 | 14.75 / 13.69% | −1.1 / −2.2%p | −3.3 / −6.1 |
| 같은 창, 작은 모델 | 6개월, 잎 15, 나무 100 | 14.96% | −0.90%p | −2.34 |
| 최근 가중(반감기) | 30 / 91 / 182일 | 14.34 / 14.92 / 15.61% | −1.5 / −0.9 / −0.3%p | −4.1 / −2.8 / −0.9 |
| 미세조정 | v5 + 최근 3개월로 나무 100개 추가 | 15.41% | −0.45%p | −1.77 |
| 말 그대로 과적합 | 3개월, 잎 127, 나무 500 | 13.81% | −2.05%p | −5.05 |
| 혼합(확률 평균) | v5 + 3개월 / 6개월 / 반감기 91일 | 14.80 / 15.49 / 15.57% | −1.1 / −0.4 / −0.3%p | −3.4 / −1.2 / −1.1 |
| (참고) 나무 수 고정 | v5를 300개 고정 | 16.19% | +0.33%p | +1.37 |

- **주 단위 재학습:** 6개월 창 −1.48%p(t −3.81), 3개월 창 −1.84%p(t −4.66)으로 월 단위와 같았다. 재학습 주기 탓이 아니다.
  - 재학습 직후 며칠의 손실도 월말과 같았다(반론 검토).
- **나무 수 교란 확인:** 짧은 창을 v5와 같은 나무 50개로 맞추거나 작은 모델로 바꿔도 손실 대부분이 남았다. 원인은 상한가 사례 수다.
  - 최근 1개월의 양성은 약 120건, 3개월은 약 580건이다. 3년 창은 약 5,000건이다.
- **반감기 91일의 1위 적중 (+4.3%p, t 2.12):** 결과를 본 뒤 찾은 신호다. 상위 2개 적중은 v5와 같다(30.1% vs 29.9%). 1·2위 순서만 바뀐 잡음으로 판단했다.
- **2026-07 이후:**
  - 6개월 혼합이 +0.9%p(t 2.16)였다. 그러나 선택 구간에서는 −0.4%p였고, 시드 평균과 비교하면 절반은 단순 평균 효과다.
  - 시장 국면별로 바꿔 쓰는 방식도 사전 규칙으로는 이득이 없었다(+0.1%p 안팎).
- **실전 병행 기록 (10/23 ~ 10/29, 5일):** 이미 기록 중인 최근 6개월·1년 모델도 v5와 차이가 없다.
  - 상위 10 적중: v5 5/50, 최근 6개월 5/50, 최근 1년 6/50
  - 1위 적중: 셋 다 1/5

## 해석과 다음 단계

1. **v5 유지.** 최근 데이터 위주 모델은 병행 기록에도 추가하지 않는다. 같은 가설은 `y_up_recent6m`·`y_up_recent1y`가 10/21부터 실전으로 기록 중이다.
2. **나무 수 고정의 이득이 더 크다 (+0.33%p, 판정 문턱 미달).** 같은 3년 자료에서 조기종료를 쓰지 않고 나무 300개로 고정한 결과다.
   - 이는 `docs/ANALYSIS_20261029.md` 2절의 조기종료·확률 스케일 문제와 같은 방향이다.
   - 다만 300개 고정은 확률이 커진다. 하루 최고 prob 중앙값이 0.36으로 v5의 0.24보다 높고, prob ≥ 0.15 픽이 늘면서 그 정밀도는 31.5%에서 26.9%로 떨어졌다.
   - 따라서 확률 스케일을 함께 손봐야 한다. 이 작업은 사용자 결정 (b)의 범위다.
