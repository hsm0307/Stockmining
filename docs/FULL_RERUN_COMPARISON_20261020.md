과거 게시 결과와의 차이는 아래 제약을 포함하므로 코드 변경의 효과와 분리해 해석해야 한다.

- 2016년은 첫 학습용이며 분기별 워크포워드 예측 평가는 2017년부터다. 2019년 이후 비교는 동일 분기 예측에서 추출한다.
- 현재 재실행 원자료는 2026-10-14까지이고 다음 거래일 라벨을 아는 예측 기준일은 2026-10-13까지다. 기존 게시 결과의 원자료는 2026-10-15까지다.
- 기존 결과의 예측 마지막 날짜 2026-10-14는 원자료 종단과 다음날 라벨 정의로 추론한 값이며, 커밋된 원시 예측파일로 직접 확인한 값이 아니다.
- 과거 게시 결과와 재실행 결과의 차이에는 데이터 종단, 원자료 개정 여부, 표본 적격성·당시 실행 소스 및 실행 라이브러리와 스레드 차이가 포함될 수 있다. 당시 원자료·특징·예측 파일이 커밋되지 않아 구성요소를 완전히 분리할 수 없다. 이 차이를 PR의 인과효과로 해석하지 않는다.
- 재실행 종단이 하루 더 이른데도 2019년 이후 적격 관측 행은 기존 게시 표보다 많다. 따라서 게시 결과 대비 차이를 단순히 마지막 하루 차이로 설명할 수 없으며, 그 이상의 표본·과거 실행 차이는 미해명 상태다.
- 두 코드 버전의 원자료 패널 전체 열 값/순서/스키마 및 특징 계산 코드가 같음을 확인하여 특징을 한 번 계산하고 공유했다. 독립적으로 특징을 두 번 계산한 실험은 아니다.
- 학습/추론/평가 함수 AST와 모델 상수를 대조했다. 동일하게 학습한 모델에서 구/신 추론 함수를 실제 호출하고, 구/신 평가 함수를 실제 호출하여 일치 여부를 확인했다.
- v1은 72개 특징의 LGBM, 커밋된 v2는 같은 72개 특징의 bag3다. bag3 첫 구성원은 동일한 시드42의 v1 학습 결과를 공유했고 시드43/44는 별도 학습했다.
- 2024년 이후 구간은 과거 모델 선택과 승격에 이미 사용되었으므로 독립적인 미사용 검증 구간이 아니다.
- 원래 게시 표는 반올림되어 있다. v2 기간 표의 5자리 비율 반올림은 최대 약 0.0005%p의 표시 오차를 만든다. 연도 표는 4자리여서 최대 약 0.005%p다.
- 수익률은 기존 모델 평가의 비용가정(왕복 0.25%)과 일별 상위 k개 평균을 유지한다. 실제 상한가 주문 체결 가능성이나 공식 기업행동 총수익을 보장하지 않는다.


## 재실행 중 발견한 추가 수정

군집별 3개월 급락률에서 수익률 결측을 급락하지 않은 사례로 세던 분모를 수정했다. 전체 군집 건수와 관측 건수, 미관측 건수, 급락 건수를 별도로 기록하고, 모든 결과가 미관측이면 급락률도 미산출한다. 이 수정은 PR 1 이후 재실행에서 발견한 후속 수정이며, 사전 패턴 분석을 다시 실행했다. 예측 특징과 모델 학습은 이 군집 사후 통계를 입력으로 사용하지 않아 재학습 결과에 영향을 주지 않는다.

## 해석 범위

사전 특징의 SMD와 군집 배정, 연속 발생 확률은 같은 원자료에서 동일했다. 다만 매집 점수별·군집별·연속 종료 후 수익률은 관측 경로 선별 영향을 받는다. 개선 후 장기 평균 손실이 줄어든 것은 표본 변화의 결과일 수 있으므로 생존편향이 해결됐거나 매매 전략이 개선됐다고 해석하지 않는다.

2017년 이후 평가는 현재의 고정 모델 설정을 과거에 적용한 분기별 재학습 결과다. v2 설정 자체는 과거 성과를 확인해 선택된 것이므로, 2024년 이후 재사용 검증 기간을 독립 최종 검증으로 부르지 않는다. 실제 사전 예측 원본 기록은 저장소에 없으므로 이번 재학습을 실전 성적으로 채점하지 않았다. 무기한 자동 탐색은 새로운 실험에 해당하여 재현 범위에 포함하지 않았다.

반복 사건과 겹치는 보유기간은 독립 표본이 아니다. 기준가격 연결지수는 기업행위와 배당이 검증된 총수익률이 아니며, 표시 수익률은 실제 체결 가능성이나 자금 배분을 반영한 포트폴리오 수익률을 뜻하지 않는다.


## 코드 시점과 완료일

보고서 완료일은 2026-10-20이다. 수치 비교는 기존 ce87af8과 2026-10-17 PR 1 병합 0b91b5f의 고정 스냅샷에 대한 것이다. 재개 시점의 원격 7e80c4b에는 이후 작업이 추가되어 있었으며, 이 보고서는 그 최신 모델·새 탐색 결과 전체를 재실행한 것으로 표시하지 않는다. 추가 군집 분모 수정은 최신 analysis_pre.py가 기존과 동일함을 확인해 적용했다.


군집 분모 수정 예: 군집 1의 전체 1,433건 중 3개월 수익률 관측 1,164건, 미관측 269건, 30% 이상 급락 267건이다. 급락률은 267/1,433=18.63%에서 267/1,164=22.94%로 수정됐다. 군집 구성이나 미래 가격 자체가 바뀐 결과가 아니다.
