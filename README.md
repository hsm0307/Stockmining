# 한국 주식 상한가·하한가 데이터마이닝 (KOSPI·KOSDAQ 10년)

데이터마이닝 팀 프로젝트. KRX Open API로 유가증권(KOSPI)·코스닥(KOSDAQ) 전 종목 일별 시세를 받아
상한가·하한가를 분석하고, **익일 상한가/하한가 예측 모델**을 만들어 발표 전 2달 동안 실전 예측합니다.

| 목표 | 질문 | 실행 명령 | 주요 결과 |
|---|---|---|---|
| 1 | 상한가·점상·하한가·점하는 몇 건, 언제, 어떤 종목에서? | `counts` | `g1_*` |
| 2 | 상·하한가 직전 20/60거래일에 특이사항(매집 흔적)이 있는가? | `pre` | `g2_*` |
| 3 | 상한가/하한가를 따라 산 개미의 수익률은? (익일·1주·1달·3달·반년·1년) | `post` | `g3_*` |
| 4 | 연속 상한가/하한가 종목의 특징은? 예측 가능한가? | `streak` | `g4_*` |
| 5 | 익일 상한가/하한가 예측 모델 + 백테스트 + 2달 실전 예측 | `backtest`, `train`, `daily` | `g5_*`, `predictions/` |

결과 표는 `outputs/tables/*.csv`(엑셀에서 바로 열림), 그림은 `outputs/figures/*.png`,
요약 보고서는 `outputs/REPORT.md` 에 생성됩니다.

## 1. 준비

### 1-1. KRX Open API 서비스 이용신청 (중요)
인증키만으로는 호출되지 않습니다. [KRX Open API](https://openapi.krx.co.kr) 로그인 → 서비스 이용 → **주식** 분류에서
아래 두 서비스를 각각 **이용신청**하고 승인을 받아야 합니다.

- 유가증권 일별매매정보 (`sto/stk_bydd_trd`)
- 코스닥 일별매매정보 (`sto/ksq_bydd_trd`)

### 1-2. 설치
```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env          # .env 파일에 KRX_API_KEY=발급키 입력 (git에 올라가지 않음)
python -m krxlimit check      # 최근 영업일 데이터가 나오면 성공
```
- Python 3.10 이상, **메모리 16GB 권장** (10년치 약 600만 행). 8GB면 `.env`에 `KRX_START=20190101` 처럼 기간을 줄이세요.
- macOS에서 lightgbm 설치 오류가 나면 `brew install libomp`. lightgbm이 없으면 자동으로 scikit-learn 모델(hgb)을 씁니다.
- API 키는 코드에 넣지 말고 `.env` 에만 두세요. 팀원은 각자 `.env` 를 만들면 됩니다.

## 2. 실행 순서

```bash
python -m krxlimit collect            # ① 2016-01-01 ~ 오늘 수집 (약 5,500회 호출, 동시 6개 요청으로 15~30분, 중단돼도 이어받기)
python -m krxlimit build              # ② 패널 생성 + 상/하한가 판정 점검표 출력
python -m krxlimit features           # ③ 특징·라벨 생성 (수 분)
python -m krxlimit analyze            # ④ 목표 1~4 분석 (counts / pre / post / streak 개별 실행도 가능)
python -m krxlimit backtest --target y_up,y_down   # ⑤ 워크포워드 백테스트 (2019~현재)
python -m krxlimit train --target y_up,y_down      # ⑥ 최종 모델 학습 → models/
python -m krxlimit predict            # ⑦ 다음 거래일 상한가/하한가 후보 → predictions/
python -m krxlimit report             # ⑧ outputs/REPORT.md
```
`python -m krxlimit all` 은 ②~⑥, ⑧ 을 한 번에 실행합니다. 각 명령의 옵션은 `python -m krxlimit <명령> -h`.

## 3. 데이터와 정의

**기간**: 2016-01-01 ~ 현재 (약 10.8년). 2015-06-15에 가격제한폭이 ±15% → **±30%** 로 바뀌었으므로
2016년부터 쓰면 한 가지 규정만 분석하게 됩니다.

**기준가격과 수익률**: `기준가 = 종가 − 대비(CMPPREVDD_PRC)`. KRX의 '대비'는 기준가 대비 등락이라,
액면분할·무상증자·감자·권리락으로 기준가가 조정된 날도 정확한 일간 수익률(`ret = 종가/기준가 − 1`)이 나옵니다.
이를 누적한 수익률지수(`ri`)로 장기 수익률을 계산하므로 수정주가가 따로 필요 없습니다(현금배당은 미반영).

**상·하한가 계산** (`krxlimit/ticks.py`)
- 가격제한폭 = 기준가 × 30%, 기준가 호가단위 미만 절사 → 상한가는 그 가격대 호가단위로 절사, 하한가는 절상
- 호가단위: 2023-01-25 이전은 유가/코스닥 별도, 이후는 통일 규정

| 용어 | 정의 (열 이름) |
|---|---|
| 상한가 | 종가 = 상한가 (`up_close`) |
| 점상 | 시가 = 고가 = 저가 = 종가 = 상한가, 하루 종일 상한가 (`up_jeom`) |
| 상한터치후이탈 | 장중 고가가 상한가에 닿았지만 종가는 상한가 아님 (`up_fail`) |
| 하한가 / 점하 / 하한터치후회복 | 위와 대칭 (`down_close`, `down_jeom`, `down_fail`) |
| n연상 | 거래일 기준 연속 상한가 일수 (`up_streak`), 거래정지일은 건너뜀 |

**분석에서 빼는 날** (`limit_valid = False`): 거래정지(거래량 0), 신규상장 첫날(공모가 기준 별도 가격제한),
정리매매 등 등락률이 ±30.5%를 넘는 가격제한 없는 날.
**상장폐지 종목도 포함**합니다(그날그날의 전 종목을 받으므로 생존편향 없음). 이후 수익률은 마지막 거래가(정리매매 포함)로 청산된 것으로 봅니다.

> `build` 후 출력되는 **판정 점검표**(`g0_limit_validation.csv`)를 꼭 확인하세요.
> 규정 계산과 "등락률 ≥ 29.5% & 종가 = 고가" 기준이 거의 일치해야 정상입니다.
> '누락 의심'이 많으면 `KRX_LIMIT_RULE=loose python -m krxlimit build` 로 비교할 수 있습니다.

## 4. 분석 방법

### 목표 1. 건수 (`analysis_counts.py`)
연도·시장별 상한가/점상/상한터치이탈/하한가/점하/하한터치회복 건수, 1만 종목일당 발생률, 월별 추이,
종목 유형(보통주/우선주/스팩/리츠)·가격대(동전주 등)·시가총액 5분위·코스닥 소속부별 발생률,
상·하한가 다발 종목 TOP 30, 요일/월 효과, 하한가가 몰린 날(시장 급락일).

### 목표 2. 직전 20/60일 특이사항 — 매집 흔적 (`analysis_pre.py`)
- **사건연구(event study)**: '첫' 상한가(직전 20일 상한가 없음) 전후 −60~+20일의 누적초과수익률(CAR)과
  비정상 거래량(과거 [−120,−61]일 중앙값 대비 로그배율). **대조군**은 같은 날·같은 시장·같은 시총 5분위에서 무작위로 3배수 추출합니다.
- **직전 20/60일 지표 비교**: 누적(초과)수익률, 거래량 증가, 거래량 추세, 급증일수, 거래 고갈일 비율, 박스권 폭, 변동성,
  장대윗꼬리(시세 테스트) 일수, CMF(자금흐름), OBV 순매수비율, 이전 상·하한가 터치 → 표준화평균차(SMD), AUC, Mann-Whitney 검정
- **매집 의심 점수(0~5)**: ①거래량 증가+가격 횡보 ②박스권(폭 30% 이하) ③OBV 매수우위+가격 정체 ④윗꼬리 시세 테스트 ⑤소형주.
  이벤트군과 대조군의 점수 분포(lift), 점수별 상한가 이후 수익률·급락(3달 −30% 이하) 비율 → "작전형 상한가는 결국 빠지는가?"
- **K-means 군집**: 직전 60일 패턴을 유형화(실루엣 점수로 k 선택), 군집별 이후 수익률 비교
- 한계: 투자자별(개인·외국인·기관) 매매 데이터가 없어 '매집'은 가격·거래량 패턴으로만 추정합니다. 특정 종목을 작전주로 단정하면 안 됩니다.

### 목표 3. 상따·하따 이후 수익률 (`analysis_post.py`)
- 진입: **당일 제한가 매수**(상한가 가격에 산 경우. 터치 후 이탈한 종목은 "물린" 경우) / **익일 시가 매수**
- 보유: 1·5·20·60·120·250 거래일 뒤 종가 매도. 평균, 중앙값, 1% 절사평균, 승률, 10/90 분위,
  시장(동일가중) 대비 초과수익, 거래비용 차감(왕복 0.25% 가정), 상장폐지 비율
- 이벤트 종류: 상따(터치 전체), 상한가 마감, 점상, 점상 제외, 터치후이탈, 첫 상한가, 2연상 이상 (하한가도 대칭)
- 분해: 시장, 연도, 시총 5분위, 종목 유형, 연속일수별 / 0~250일 평균 누적수익률 경로 그림
- **평균과 중앙값을 같이 보세요.** 소수 대박 종목이 평균을 끌어올리고 대부분은 손실인 경우가 흔합니다.

### 목표 4. 연속 상·하한가 (`analysis_streak.py`)
- 연속 길이 분포, **k일 연속 → k+1일째 이어질 확률**(95% 신뢰구간), 첫날 점상 여부·시장별 비교
- 오늘 상태(상한가/터치이탈/+10%↑/…/하한가) → 내일 상태 **전이 확률 행렬**
- 첫 상한가 다음 날 연상 성공 vs 실패 종목의 특징 비교
- **예측 가능성**: 상한가 마감 종목만 대상으로 "내일도 상한가?" 분류 — 로지스틱 회귀(표준화 계수로 해석),
  의사결정나무(깊이 4, 규칙 텍스트·그림), 그래디언트 부스팅(순열 중요도). 시간 기준 분할(과거 70% 학습 → 최근 30% 검증),
  기준선(연속일수+점상 규칙)과 AUC·AP·상위10% 적중률 비교, 예측 10분위별 실제 연상률
- 연상이 끝난 뒤 수익률(연상 길이별)

### 목표 5. 익일 상한가/하한가 예측 (`features.py`, `model.py`, `live.py`)
**문제 정의**: 매일 장 마감 후 전 종목(약 2,600개)에 대해 *다음 거래일 상한가 마감 확률*을 계산하고 상위 k개를 고릅니다.
상한가는 하루 전체의 0.5% 안팎이라 정확도(accuracy)는 의미가 없습니다(전부 "아니오"라고 해도 99.5%).
그래서 **P@k(상위 k개 중 실제 상한가 비율)**, **Lift(무작위 대비 배수)**, **AP(PR 곡선 면적)**, AUC를 봅니다.

**특징 72개** (모두 당일 장 마감 후 알 수 있는 값, `FEATURE_GROUPS` 참고)

| 그룹 | 예 |
|---|---|
| candle | 당일 등락률, 갭, 몸통, 윗/아랫꼬리, 고저폭, 종가 위치, 상한가까지 거리 |
| momentum | 5/20/60/120일 수익률, 이동평균 이격도, 52주 고/저 대비 위치, 60일 박스권 폭 |
| limit_hist | 오늘 상한가/점상/터치이탈, 연속일수, 최근 20/60/250일 상·하한가 횟수, 마지막 상한가 후 경과일 |
| volume | 거래대금(로그), 회전율, 거래량 배율(1/20일, 5/60일), 거래대금 순위, 급증일수, 고갈일 비율 |
| volatility | 20/60일 변동성 |
| accumulation | CMF, OBV 변화, 상승일 거래량 비중, 윗꼬리 시세 테스트 횟수 |
| size_type | 주가(로그), 동전주, 시가총액·순위, 코스닥/우선주/스팩/리츠/관리종목/투자주의환기, 상장 경과일 |
| market | 시장 동일가중 수익률(1/5일), 시장 상·하한가 종목 수, 상승 종목 비율 |
| peer | **동조 종목(테마 대용)**: 직전 120일 수익률 상관이 가장 높은 10종목의 당일 평균수익률·상한가 수 (매월 과거 데이터로만 재선정) |

**모델**: LightGBM(기본, 없으면 scikit-learn HistGradientBoosting), 음성 표본 10% 추출 학습 후 확률 보정,
학습기간 마지막 60거래일로 조기종료. 비교 기준선은 "오늘 상한가 → 연속일수 → 등락률" 단순 규칙입니다.

**워크포워드 백테스트**: 2019년부터 분기마다 *그 전까지의 데이터로만* 다시 학습해 다음 분기를 예측합니다(미래 정보 누출 없음).
결과는 `outputs/tables/experiments.csv` 에 한 줄씩 누적되어 실험끼리 비교할 수 있습니다.

```bash
python -m krxlimit backtest --target y_up                         # 기본
python -m krxlimit backtest --target y_up --drop-groups peer       # 특징 그룹 제거
python -m krxlimit backtest --target y_up --exclude spac,mgmt      # 스팩·관리종목 제외
python -m krxlimit backtest --target y_up --params '{"num_leaves": 63, "min_child_samples": 100}'
python -m krxlimit backtest --target y_up --freq MS                # 매월 재학습
python -m krxlimit backtest --target y_uptouch                     # 라벨 변형: 장중 상한가 터치
python -m krxlimit ablation --target y_up                          # 그룹 하나씩 빼며 기여도 측정
```

  `actual_events_rank.csv` 실제 상한가 종목이 우리 순위에서 몇 위였는지.

### 자동 개선 탐색 (`python -m krxlimit improve`)
백테스트로 더 나은 버전을 찾아 v2, v3… 으로 승격하는 절차를 한 명령으로 돌립니다 (`krxlimit/improve.py`).

```bash
python -m krxlimit improve --target y_up --promote     # 약 1시간. 결과: g5_improve_dev_y_up.csv, g5_improve_holdout_y_up.csv
python -m krxlimit daily --suffix _v2                    # 승격된 v2 로 매일 예측 (v1 과 병행)
```
1. **개발 구간(2019~2023)** 에서만 후보를 비교합니다. 연 1회 재학습 워크포워드로 빠르게 돌립니다.
2. 후보와 현재 챔피언을 **같은 날짜끼리 짝지어** 상위 10개 적중 수 차이를 검정(paired t)합니다.
   평균 차이 > 0 이고 t ≥ 1 일 때만 채택합니다. 우연한 개선을 거르기 위한 장치입니다.
3. 라운드: ① 새 특징 그룹 추가(`rel_strength` 오늘 상한가 종목끼리의 회전율·거래대금 순위,
   `pref_link` 우선주↔보통주, `stock_hist` 종목의 과거 연상 비율, `market2` 시장 과열/실패 분위기, `peer2` 동조종목 터치 수)
   ② 하이퍼파라미터 ③ 모델 종류(`bag3` 배깅, `rank` 날짜별 순위학습 LambdaRank, `ens` 앙상블) ④ 학습 기간·대상 종목
4. 최종 챔피언은 **한 번도 안 본 보류 구간(2024~현재)** 에서 v1 과 다시 비교하고(분기 재학습),
   나빠지지 않을 때만 `configs/{target}_vN.json` 과 `models/{target}_vN.pkl` 로 승격합니다.
5. 실전 기간에는 v1(고정 설정)과 새 버전을 함께 예측해 `predictions/` 성적표로 비교합니다.
   매주 재학습은 각 버전의 설정(meta)을 그대로 써서 최신 데이터까지 다시 학습합니다.

### 장시간 자동 개선 (`python -m krxlimit evolve`)
`improve` 를 사람이 멈출 때까지 반복하는 버전입니다. 상한가·하한가 모델을 번갈아 개선합니다.
```bash
python -m krxlimit evolve --target y_up,y_down --hours 1.8   # 끝나면 다시 실행 → 저장된 상태에서 이어서 진행
```
- 개발 구간은 **2017~2023(7년)** 입니다. 2016년은 첫 학습용입니다.
- 검증은 **2017~현재(약 10년) 분기 재학습 워크포워드**로 하고, 승격 판정은 보류 구간(2024~)으로 합니다.
- 먼저 체계적 후보(새 특징 그룹, 파라미터, hard negative, 모델 종류, 학습기간)를 시험하고,
  그다음 현재 챔피언 설정을 무작위로 1~2개 바꾼 변이 후보를 계속 시험합니다.
- 개발 챔피언이 바뀌면 10년 백테스트로 운영 버전과 비교합니다. 보류 구간에서 나쁘지 않으면 `configs/{target}_vN.json` 으로 승격하고,
  나쁘면 운영 버전으로 되돌립니다.
- 진행 상황 파일
  - `outputs/evolve/state_*.json` 진행 상태
  - `outputs/tables/g5_evolve_board_*.csv` 시도한 후보 전체
  - `g5_evolve_versions_*.csv` 승격 이력
  - `g5_10y_*` 최근 10년 검증표
  - `outputs/figures/g5_evolve_*.png` 진행 그래프
- 결과는 매 단계 자동으로 커밋됩니다. 보류 구간을 여러 번 확인하면 그 구간에도 조금씩 맞춰질 수 있습니다.
  최종 성능은 실전 예측(`predictions/`)으로 확인하세요.
- 승격된 버전으로 예측: `python -m krxlimit train --config configs/y_up_v2.json` (다른 PC) → `python -m krxlimit daily --suffix _v2`

**정확도를 높이는 방법 (체크리스트)**
1. 지표 고정: P@10, Lift@10, AP. 모든 실험은 같은 워크포워드 구간으로 비교 (`experiments.csv`).
2. **과최적화 방지**: 2019~2023년으로만 튜닝하고(`backtest --start 2019-01-01` 후 연도별 성적 확인),
   2024년 이후는 마지막 확인용으로 남겨 두기. 실전 2달이 진짜 홀드아웃입니다.
3. 특징 그룹 ablation → 기여 없는 그룹 제거, 새 특징 추가(아래 확장 아이디어).
4. 하이퍼파라미터: `num_leaves`, `min_child_samples`, `learning_rate`, `--neg-rate`(0.05~0.3).
5. 대상 종목 필터(`--exclude`)와 라벨 변형(`y_uptouch`)으로 문제를 쉽게 만들 수 있는지 확인.
6. 재학습 주기(`--freq QS` vs `MS`): 최근 시장 분위기를 빨리 반영하는지.
7. 운영 임계값: `g5_threshold_*.csv` 에서 "확률 X% 이상만 추천" 시 정밀도·하루 추천 수를 보고 확신 구간을 정함.
8. 실전에서는 v1(고정)과 재학습 모델을 같이 돌려 데이터 누적 효과를 측정.

**확장 아이디어**: 투자자별 매매동향(개인/외국인/기관), DART 공시(유상증자·CB 발행·최대주주 변경), 뉴스/테마 키워드,
투자경고·투자위험 지정 이력 — 매집과 상한가 예측에 모두 도움이 될 가능성이 큽니다.

## 6. 폴더 구조
```
krxlimit/            분석 패키지
  config.py          경로·기간·규정 상수 (.env 읽기)
  krx_api.py         KRX Open API 클라이언트
  collect.py         일별 수집 (data/raw/{시장}/{연도}/{YYYYMMDD}.parquet, 이어받기)
  ticks.py           호가단위·상하한가 계산
  panel.py           패널 생성, 상/하한가 판정, 연속일수, 판정 점검
  features.py        특징·라벨 (룩어헤드 없음), 동조 종목 특징
  events.py          이벤트 이후 수익률 계산 공통
  analysis_counts.py / analysis_pre.py / analysis_post.py / analysis_streak.py   목표 1~4
  model.py           목표 5 모델·워크포워드 백테스트·실험 기록
  live.py            실전 예측 저장·채점
  report.py          outputs/REPORT.md 생성
tests/               합성 데이터 기반 테스트 (python -m pytest)
predictions/         실전 예측 기록 (git에 커밋)
```
`data/`, `models/` 는 용량이 커서 git에서 제외됩니다. 팀원은 각자 `collect` 로 받으면 됩니다.

## 7. 테스트
```bash
python -m pytest -q
```
합성(가짜) 시세로 수집 → 패널 → 특징 → 분석 → 백테스트 → 학습 → 예측 → 채점 → 보고서 전 과정이 돌아가는지,
상·하한가 계산 규칙, 특징에 미래 정보가 섞이지 않는지(데이터를 잘라서 다시 계산해도 값이 같은지),
실시간 예측(최근 560일만 계산)과 전체 계산의 특징값이 같은지 검사합니다. 합성 데이터의 수치는 분석 결과가 아닙니다.

## 8. 주의
- 교육용 분석입니다. 투자 권유가 아니며, 백테스트 수익은 체결 가능성(점상은 사실상 매수 불가)·슬리피지를 완전히 반영하지 못합니다.
- 수익률은 현금배당을 포함하지 않은 가격 수익률입니다.
- '매집 의심'은 패턴 기반 추정이며 특정 종목의 불공정거래를 의미하지 않습니다.
